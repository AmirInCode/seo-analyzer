# تحلیلگر سئوی مقالات با هوش مصنوعی

ابزاری که با گرفتن **آدرس یک مقاله** و **کلمه کلیدی هدف**، محتوای صفحه را استخراج می‌کند، بیش از ۲۵ معیار سئو را می‌سنجد، امتیاز ۰ تا ۱۰۰ می‌دهد و در پایان یک تحلیل کیفی تخصصی با یک مدل زبانی ارائه می‌کند.

بخش هوش مصنوعی از هر ارائه‌دهنده‌ی **سازگار با OpenAI** کار می‌کند (Groq، NVIDIA، Ollama محلی و…). فقط `AI_BASE_URL` و `AI_MODEL` را در `.env` عوض کنید.

## راه‌اندازی

```bash
npm install
```

سپس فایل `.env` را بسازید:

```bash
cp .env.example .env
```

### گزینه‌ی پیش‌فرض: Groq (رایگان و سریع)

کلید رایگان را از [console.groq.com/keys](https://console.groq.com/keys) بگیرید و در `.env` بگذارید:

```
GROQ_API_KEY=gsk_...
AI_BASE_URL=https://api.groq.com/openai/v1
AI_MODEL=llama-3.3-70b-versatile
```

### گزینه‌ی محلی: Ollama (بدون کلید، آفلاین)

اگر [Ollama](https://ollama.com) نصب دارید:

```bash
ollama pull qwen3:8b
```

و در `.env`:

```
AI_BASE_URL=http://localhost:11434/v1
AI_MODEL=qwen3:8b
```

### اجرا

```bash
npm start
```

سپس به `http://localhost:3000` بروید.

> بدون کلید API هم برنامه کار می‌کند — فقط بخش «تحلیل هوش مصنوعی» غیرفعال می‌شود و بقیه‌ی گزارش کامل ارائه می‌گردد.

### پشت فیلترشکن هستید؟

سرویس‌هایی مثل Groq در برخی کشورها محدودیت جغرافیایی دارند. اگر خطای **۴۰۳ Forbidden** گرفتید، آدرس پروکسی/فیلترشکن خود را در `.env` بگذارید تا درخواست‌های هوش مصنوعی از آن عبور کنند:

```
AI_PROXY=http://127.0.0.1:10808
```

(پورت را با پورت واقعی ابزار خودتان جایگزین کنید — مثلاً v2ray/xray معمولاً روی `10808` است.)

## سیستم امتیازدهی

جمع وزن‌ها ۱۰۰ امتیاز است:

| بخش | وزن | معیارها |
|---|---|---|
| **Content SEO** | ۲۰ | طول مقاله (۱۰)، تنوع واژگان (۵)، ساختار پاراگراف‌ها (۵) |
| **Technical SEO** | ۲۰ | Title (۷)، Meta Description (۷)، Canonical (۳)، Open Graph (۳) |
| **Structure SEO** | ۱۵ | H1 (۵)، H2 (۴)، H3 (۳)، سلسله‌مراتب هدینگ (۳) |
| **Keyword Optimization** | ۲۰ | Title (۵)، H1 (۴)، Meta (۳)، پاراگراف اول (۳)، چگالی (۳)، زیرعنوان‌ها (۲) |
| **Readability** | ۱۵ | طول جملات (۶)، طول پاراگراف‌ها (۶)، زمان مطالعه (۳) |
| **Links** | ۱۰ | لینک داخلی (۵)، لینک خارجی (۵) |

هر معیار سه حالت دارد: **قبول** (امتیاز کامل)، **هشدار** (نصف امتیاز)، **رد** (صفر).

### درجه‌بندی کیفیت

| امتیاز | درجه |
|---|---|
| ۸۵–۱۰۰ | Excellent (عالی) |
| ۷۰–۸۴ | Good (خوب) |
| ۵۰–۶۹ | Average (متوسط) |
| ۰–۴۹ | Poor (ضعیف) |

## خروجی گزارش

- امتیاز کلی ۰ تا ۱۰۰ + درجه‌ی کیفیت
- امتیاز تفکیکی هر یک از ۶ بخش
- آمار مقاله (کلمات، پاراگراف، هدینگ‌ها، تصاویر، لینک‌ها، چگالی کلیدواژه، زمان مطالعه و…)
- مشکلات مهم، هشدارها و نقاط قوت
- فهرست پیشنهادهای اصلاحی
- **تحلیل هوش مصنوعی**: ارزیابی کلی، امتیاز کیفیت محتوا، تطابق با قصد جستجو، موضوعات جاافتاده، پیشنهادهای اولویت‌بندی‌شده، عناوین جایگزین و متادیسکریپشن پیشنهادی

## ساختار پروژه

```
server.js            سرور Express و مسیر /api/analyze
src/fetcher.js       اعتبارسنجی آدرس و دریافت HTML
src/parser.js        استخراج متادیتا، هدینگ‌ها، متن، تصاویر و لینک‌ها
src/analyzer.js      موتور امتیازدهی و تولید یافته‌ها
src/ai.js            تحلیل کیفی با مدل زبانی سازگار با OpenAI (Groq/NVIDIA/Ollama)
public/              رابط کاربری فارسی و راست‌به‌چپ
```

## API

```
POST /api/analyze
Content-Type: application/json

{ "url": "https://example.com/article", "keyword": "کلمه کلیدی", "useAI": true }
```

پاسخ شامل `score`، `grade`، `sections`، `stats`، `issues`، `warnings`، `strengths`، `recommendations` و `ai` است.

## محدودیت‌ها

- صفحاتی که محتوایشان با جاوااسکریپت رندر می‌شود (SPA) استخراج نمی‌شوند؛ ابزار فقط HTML اولیه را می‌خواند.
- سایت‌هایی که ربات‌ها را مسدود می‌کنند ممکن است خطای دسترسی برگردانند.
- حداکثر حجم صفحه ۵ مگابایت و مهلت دریافت ۲۰ ثانیه است.
- تشخیص بدنه‌ی مقاله مبتنی بر heuristic است و در قالب‌های غیرمتعارف ممکن است دقیق نباشد.
